# 漫画坞 MangaDock

连 WebDAV 看漫画的 iOS 客户端。自己写的，没广告、没账号、不联网校验，只连你自己的服务器。

最低 **iOS 18**；在 **iOS 26** 上自动使用 Liquid Glass（底栏、工具栏、阅读器悬浮条由系统渲染玻璃）。
界面全部是原生 SwiftUI + UIKit（`UIPageViewController` 翻页、`Core Image` 增强），没有第三方框架。

## 能干什么

- **底栏标签可配置**：书架 / 文件 / 记录 / 设置，设置里能关掉不用的（记录默认关闭，设置页不让关）
- **书架和 WebDAV 目录分离**：书架只放你自己挑的。在「文件」里长按任意漫画 →「加入书架」，
  书架首页显示封面缩略图，点进去是**章节列表**（带每话进度 + 顶部「继续阅读」）
- **WebDAV 浏览**：填服务器地址 + 账号密码，直接按目录翻你的漫画库；长按可加入/移出书架
- **每个目录单独记视图**：书架可以是网格，某个二级目录可以是列表，互不影响；新目录默认用设置里的选项
- **列表 / 网格两种视图**：右上角一键切换，网格带封面缩略图（2:3 卡片）
- **长按换封面**：长按网格里的封面 → 从相册选图，自动居中裁成 2:3；长按菜单里可恢复默认封面
- **CBZ / ZIP / PDF 直读**：点开即下载到本地缓存（有进度条），自动按自然序排页（第2话 在 第10话 前面）
- **散图文件夹**：一个文件夹里全是 jpg/png 也能当一话读，图片按需下载并缓存
- **连续阅读**：一话读完自动出现「本话看完」页，点一下进下一话；顶部显示「第 3 / 12 话」
- **翻页阅读器**：左右滑动；点左/右三分之一翻页，点中间收起工具栏；工具栏隐藏后任意点击恢复
- **默认阅读方式**：设置里可选左右翻页或上下滚动，阅读器右上角可临时切换
- **条漫模式**：竖向连续滚动，点页面本身切换工具栏；底栏只留「上一话 / 隐藏 / 下一话」
- **明亮 / 黑暗主题**：设置里三选一（跟随系统 / 明亮 / 黑暗）
- **画质增强**：阅读器右上角 `✨` 开关，本地 GPU 做 2 倍 Lanczos 上采样 + 锐化（见下）
- **标题不带后缀**：`第01话.cbz` 显示成「第01话」，目录名保持原样
- **进度记忆**：退出记住页码，「记录」标签里带进度条，点一下回到上次位置
- **内存友好**：图片按屏幕分辨率降采样，翻页只保留相邻 3 页；增强结果按页缓存
- **在线漫画（by URL）**：书架右上角 ＋ 粘贴网页地址；单话页解析图片直接读，
  目录页识别各话链接生成章节列表；在线漫画也记进度，退出后书架封面显示进度条、点进去回到上次位置


### 连续阅读的规则

同一父目录下的**同类型**兄弟项会串成一季：看 CBZ 就往下串 CBZ，看图片文件夹就串其他文件夹。
章节按自然序排（第2话 在 第10话 前），跨卷、跨子目录不会乱串。父目录读不到（权限/离线）时
就退化成单话，不显示「下一话」。


### 网格封面怎么来的（不整本下载）

覆盖三层策略，逐层降级：

1. 这本书已经读过（本地有缓存）→ 直接从本地 CBZ 里取第一页
2. 是散图文件夹 → 取文件夹里第一张图
3. 远程 CBZ 且没缓存 → **HTTP Range 只读压缩包尾部**，解析 EOCD / 中央目录拿到第一张图的偏移，
   再按 Range 取那一页的压缩数据解压成缩略图

第 3 步要求服务器支持 `Range` 请求（nginx dav、Alist、群晖都支持）。服务器不支持时会退化成
带书名和文件大小的占位卡片，**不会**为了显示封面去下载整本。封面缓存在 `Caches/MangaDock/covers`。

## 画质增强：GPU 快速增强 + AI 超分

两层引擎，自动配合：

**1. GPU 快速增强（默认，实时）**：`ImageEnhancer` 的 2 倍 Lanczos 上采样（输出封顶 3000px）+ unsharp 锐化，
跑在 `CIContext` 上，一页几十毫秒。对低清扫描件有效，但不生成新细节。

**2. AI 超分（已内置 Real-ESRGAN）**：内置 `RealESRGAN_x4plus_anime_6B`（Core ML，ML Program fp16，约 8 MB，
BSD-3-Clause 授权，专为动漫/漫画训练）。开启增强后，先在 GPU 管线上快速增强，再叠加 AI 超分重建细节。

AI 超分走**分块（tile）推理**：模型输入固定 512×512，大图切成重叠方块逐块超分再拼接，重叠区裁剪消除接缝。
输出倍数可选 2 倍 / 4 倍（设置页），一页约数秒（4 倍更慢、更占内存）。

模型放在 `MangaDock/Resources/SuperResolution.mlpackage`，`AIEnhancer.swift` 负责加载与推理。
授权文件（`LICENSE.txt` / `ATTRIBUTION.txt`）随包分发，模型权重来自
[Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN)（Xintao Wang 等，BSD-3-Clause），
Core ML 转换来自 [archwiz-upscalers](https://huggingface.co/ddutchie/archwiz-upscalers)。

**AI 上色**没有内置。原因很直接：它同样依赖模型（漫画上色专用 GAN 或云端接口），而且对黑白线稿的
上色质量在手机端普遍不稳，一页要几秒到几十秒。要做的话优先走云端接口（可插拔 provider + 你自己的 API key），
不适合塞进当前这个纯本地、零依赖的架构里。


## 不支持的

| 格式 | 状态 |
|---|---|
| CBZ / ZIP | 支持 |
| PDF | 支持（整本下载后逐页渲染成图，长边封顶 2400px） |
| 图片文件夹 | 支持 |
| CBR / RAR | 不支持（先转 CBZ） |
| 加密 ZIP | 不支持 |
| ZIP64（>4GB 或 >65535 个文件） | 不支持 |

PDF 的封面只有在本地下过之后才能生成（没有 Range 取页那套办法），没缓存时显示占位卡。


## 构建

没有 Mac 也能出 IPA —— 编译跑在 GitHub Actions 的 macOS runner 上。

推送到 `main` 或手动触发 `Build IPA` workflow，产物在 Actions 页面的 **Artifacts → MangaDock-ipa**。

本地有 Mac 的话：

```bash
brew install xcodegen
xcodegen generate
open MangaDock.xcodeproj
```

## 安装（侧载）

产物是**未签名** IPA，用你现有的侧载环境签。要求设备系统 **iOS 18 或更高**（iOS 26 自动上液体玻璃）：

1. **SideStore / AltStore**：下载 `MangaDock.ipa` → App 内安装 → 它会用你的 Apple ID 证书现场签名
2. **LiveContainer**：直接把 ipa 丢进去运行

首次打开如果连不上，检查：

- 服务器地址是否指向**漫画目录**（不是站点根）
- 局域网地址在 Wi-Fi 下能不能访问（`http://IP:端口/dav/...`）
- 账号密码是否是 WebDAV 专用账号

## 项目结构

```
MangaDock/
├── App/            入口 + 根视图
├── Core/           模型、缓存、ZIP 解析、封面、图片解码与增强
├── Net/            WebDAV 客户端、Range 读远程 ZIP
└── Views/          底栏、书架、记录、浏览、阅读器、设置、网格
```

ZIP 解析是自己写的（`Core/ZipArchive.swift`），只依赖系统 `Compression`，没有第三方包 —— 云编译不会卡在拉依赖上。
